  ШАГИ ДЛЯ РЕШЕНИЯ ПРОБЛЕМЫ
═══════════════════════════════════════════════════════════════

1. ПРОВЕРЬТЕ DNS НАСТРОЙКИ В VERCEL
   ────────────────────────────────
   Зайдите в Vercel Dashboard → Settings → Domains
   
   Убедитесь что у вас настроены правильные DNS записи:
   
   Для корневого домена (dicresp.com):
   ┌─────────────────────────────────────────────┐
   │ Type: A                                     │
   │ Name: @                                     │
   │ Value: 76.76.21.21                         │
   └─────────────────────────────────────────────┘
   
   Для www поддомена (www.dicresp.com):
   ┌─────────────────────────────────────────────┐
   │ Type: CNAME                                 │
   │ Name: www                                   │
   │ Value: cname.vercel-dns.com                │
   └─────────────────────────────────────────────┘

2. ОЧИСТИТЕ КЕШ VERCEL
   ────────────────────
   В терминале выполните:
   
   vercel --prod --force
   
   Или через Vercel Dashboard:
   Deployments → ... (три точки) → Redeploy → Use existing Build Cache: OFF

3. ПРОВЕРЬТЕ SSL СЕРТИФИКАТ
   ─────────────────────────
   В Vercel Dashboard → Settings → Domains
   Убедитесь что статус SSL: "Valid"
   
   Если статус "Pending" или "Error":
   - Удалите домен
   - Подождите 5 минут
   - Добавьте домен заново

4. ОЧИСТИТЕ DNS КЕШ НА ВАШЕМ КОМПЬЮТЕРЕ
   ─────────────────────────────────────
   Windows:
   ipconfig /flushdns
   
   Mac:
   sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
   
   Linux:
   sudo systemd-resolve --flush-caches

5. ПРОВЕРЬТЕ DNS ПРОПАГАЦИЮ
   ────────────────────────
   Откройте: https://dnschecker.org
   Введите: dicresp.com
   
   Проверьте что DNS записи видны по всему миру
   (может занять до 48 часов)

6. ТЕСТИРОВАНИЕ
   ────────────
   Откройте браузер в режиме инкогнито
   Зайдите на: https://dicresp.com
   
   Откройте DevTools (F12) → Network
   Проверьте:
   - Все файлы загружаются с кодом 200
   - Нет ошибок CORS
   - Нет редиректов на старый домен

7. ПРОВЕРКА СКОРОСТИ
   ─────────────────
   Откройте: https://pagespeed.web.dev
   Проверьте: https://dicresp.com
   
   Если скорость низкая:
   - Проверьте что используется CDN (должен быть)
   - Проверьте регион деплоя в Vercel (должен быть ближайший к вашим пользователям)

═══════════════════════════════════════════════════════════════
  ДОПОЛНИТЕЛЬНЫЕ ПРОВЕРКИ
═══════════════════════════════════════════════════════════════

ПРОВЕРКА 1: Правильность DNS
────────────────────────────
В терминале:
nslookup dicresp.com

Должно показать IP: 76.76.21.21

ПРОВЕРКА 2: SSL сертификат
──────────────────────────
В браузере откройте dicresp.com
Нажмите на замок в адресной строке
Проверьте что сертификат выдан для dicresp.com

ПРОВЕРКА 3: Редиректы
─────────────────────
В терминале:
curl -I https://dicresp.com

Проверьте что нет редиректов (301/302)
Должен быть код 200

4. Подождите 24 часа для полной DNS пропагации

  ВАЖНО
═══════════════════════════════════════════════════════════════

После внесения изменений в код:
1. Закоммитьте изменения: git add . && git commit -m "fix: domain config"
2. Запушьте на GitHub: git push
3. Vercel автоматически задеплоит новую версию
4. Очистите кеш браузера (Ctrl+Shift+Delete)
5. Проверьте сайт в режиме инкогнито

Обычно проблема решается в течение 1-24 часов после правильной настройки DNS.
